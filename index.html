Simple Github Readme Guide

By @denguemon

1. Moving Stuff Around (Alignment)

div tags for positioning layouts.

To explicitly keep things on the left:

<div align="left">
    This text stays on the left.
</div>

To center your stuff:

<div align="center">
    This text is centered.
</div>

To push things all the way to the right:

<div align="right">
    This text goes to the right.
</div>

4. Writing in Color

LaTeX block scripts for bypassing color block configurations.

$\color{#HexColorCode}{\text{Your text here}}$

Example to get bright green text:

$\color{#00AC60}{\text{This text is custom green}}$

5. Good Tools to Use

  • SVG Gradient Map Filter: online tool for recoloring assets into unified themes.
  • Shields.io: badge creator for generating colorful custom status templates.
  • hits.sh: tracker badges for counting total channel traffic visits.
