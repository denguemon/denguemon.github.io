GitHub Profile Customization Guide

By @denguemon

1. Moving Stuff Around (Alignment)

Normally, GitHub pushes all your text and images to the left side. If you want to force your stuff to stay on the left, center, or right, wrap it in these blocks:

To explicitly keep things on the left:

<div align="left">
    This text stays on the left.
</div>

To center your text, pony sprites, or banners:

<div align="center">
    This text is centered.
</div>

To push things all the way to the right:

<div align="right">
    This text goes to the right.
</div>

2. Adding Links

Want a clickable link? Put the word people click inside square brackets `[ ]` and the website link inside normal parentheses `( )` right next to it with no spaces:

[Check out my website](https://github.io)

3. Adding Images & Resizing

To dump an image straight onto your profile, start with an exclamation mark `!`, put a random description inside `[ ]`, and drop the direct image link inside `( )`:

![Cool Profile Banner](https://unsplash.com)

Where to Host Your Images

GitHub needs links that end exactly in `.png`, `.jpg`, or `.gif` to show your graphics. Use these free spots to host your art files:

  • File Garden: Great for saving your custom pixel art sprites and templates permanently.
  • Catbox.moe: Super quick and easy host to get clean, direct file links.

Fixing Giant Images (Sizing)

Normal Markdown doesn't let you change photo sizes, so your graphics might end up huge. Use this HTML tag instead to lock the width. The height will fix itself automatically so it doesn't look stretched:

<img src="your-image-link.png" width="200" />

4. Writing in Color

GitHub blocks regular text color codes. To cheat the system and get colored text on your profile, you have to use math codes. Copy this template exactly, swap the hex color code, and type your text inside the final `{ }` block:

$\color{#HexColorCode}{\text{Your text here}}$

Example to get bright green text:

$\color{#00AC60}{\text{This text is custom green}}$

5. Good Tools to Use

Check out these websites to make your layout look way better:

  • SVG Gradient Map Filter: Cool tool to add nice color overlays onto your graphics.
