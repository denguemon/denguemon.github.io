GitHub Markdown Profile Customization Guide

By @denguemon

This guide explains how to format, design, and decorate a GitHub profile README using Markdown, custom HTML layouts, graphics tools, and badges.

1. Text Alignment

By default, everything in a GitHub README aligns to the left. You can control layout alignments using standard HTML tags inside your Markdown file.

To center text, images, or assets:

<div align="center">
    This text and any assets here will be centered.
</div>

To align text or assets to the right:

<div align="right">
    This text and any assets here will move to the right side.
</div>

2. How to Add Links

Adding clickable text hyperlinks inside your profile README is easy. Put the text you want users to click inside square brackets, followed by the actual web URL inside parentheses.

[Click here to see my website](https://github.io)

3. How to Add Photos & Images

To display an image directly on your profile, use an exclamation mark first, then an alt-text description inside square brackets, followed by the direct image file URL inside parentheses:

![My Custom Banner Image](https://your-image-url-here.png)

Recommended Image Hosting Platforms

Since you need direct file links (ending in .png, .jpg, or .gif) to make images show up on GitHub, use these free image and asset hosting options:

  • File Garden: An excellent free platform for uploading permanent digital assets, pixel art sprites, and custom graphics templates.
  • Catbox.moe: A simple file host that provides fast, direct raw file URLs perfect for custom README badges and images.

Image Sizing

Standard Markdown tags do not allow you to resize photos. To prevent layout scaling issues, use the HTML image tag to specify the width or height explicitly.

<img src="your-image-url-here.png" width="200" />

Using just width (in pixels) forces the height to scale down proportionally so the image stays in shape.

4. How to Add Colored Text

GitHub strips away normal HTML inline styling for colors. To bypass this restriction and insert colored text on a README profile, you must use standard LaTeX math markup blocks.

To write text in a specific color, use this syntax pattern:

$\color{HexColorCode}{\text{Your text here}}$

Example for bright green text:

$\color{#00AC60}{\text{This text is custom green}}$

5. Gradient Map Websites

Gradient mapping allows you to recolor assets or text visuals to fit a unified color palette.

  • SVG Gradient Map Filter: Excellent tool for creating custom SVG filter overlays to gradient-map graphics inside digital web layouts.

6. Badge Websites

Badges add compact, stylized, color-coded rows of data to share stats, socials, or tools used.

  • Shields.io: The standard platform for creating static or dynamic technical badges. Use it to generate color blocks containing custom text and brand icons.
  • hits.sh: Simple counter badge that logs how many views your profile repository receives.

7. Graphic Design Platforms

Custom assets, banners, transparent profile margins, and text titles require raster or vector image editors before uploading to GitHub.

  • Pixlr: A web-based photo editor suitable for quick transparent cropping, layering, and canvas sizing directly in the browser.
  • ibisPaint: Popular mobile-friendly illustration tool capable of handling pixel art layouts and precise asset scaling.
  • Procreate: Advanced tablet illustration engine used for high-fidelity custom banners, hand-drawn graphics, and detailed profile artwork assets.
