🦄 Pony Town Style README Guide 🦄

By @denguemon

Want to make your GitHub profile README look amazing just like the Pony Town community does? Here is the exact Markdown code you need to copy and use!

1. Headers (Sizing Your Text)

Use hashtags to make text big or small. Make sure to put a space after the hashtag!

# Big Title (H1)
## Section Title (H2)
### Smaller Heading (H3)

2. Fancy Text Styles

To make text bold, italic, or strikeout for aesthetic notes:

*this text will be italic*
**this text will be bold**
~~this text will have a line through it~~

3. Centering & Layouts (The Secret Sauce)

GitHub Markdown allows HTML elements. To center your graphics, pony sprites, or text intro, use this layout wrapper:

<div align="center">
    
    # 🦄 Welcome to my Profile! 🦄
    
    This text and any images placed here will be perfectly centered.
    
</div>
