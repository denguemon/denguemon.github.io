Ropes of Readme!

This page is a tutorial for the basics of GitHub readmes. if its helpful, maybe follow @denguemon on github!

Alignment

1. Moving Stuff Around

Use div tags to control where content sits on the page.

Left

<div align="left">
    This text stays on the left.
</div>

Center

<div align="center">
    This text is centered.
</div>

Right

<div align="right">
    This text goes to the right.
</div>
Links

2. Adding Links

Use brackets and parentheses to make clickable links.

[Check out my website](https://github.io)
Images

3. Adding Images & Resizing

Use an exclamation mark plus a link to display an image.

![Cool Profile Banner](https://unsplash.com)

Where to host images

  • File Garden: for permanent digital assets and art.
  • Catbox.moe: quick file hosting for raw image links.

Fixing giant images

Set a width so the image stays at a manageable size.

<img src="your-image-link.png" width="200" />
Writing

4. Writing

Use custom styling to make specific words or lines stand out from the rest of the page.

Dropdown text is a reveal-style block: a short heading appears first, and clicking the arrow shows the hidden content below it.

<details>
    <summary>Click me</summary>
    This is the hidden content that appears when the dropdown opens.
</details>

To change the color of a single sentence or word:

<span style="color:#00AC60;">This text is custom green</span>

If you want a slightly more advanced version, you can also use color markup:

$\color{#00AC60}{\text{This text is custom green}}$
Tools

5. Good Tools to Use

  • SVG Gradient Map Filter: recolor assets into a consistent visual theme.
  • Shields.io: make colorful badge-style labels.
  • hits.sh: track traffic with a visitor badge.
