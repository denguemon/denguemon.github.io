1. Text Alignment

By default, everything in a GitHub README aligns to the left side. You can explicitly force elements to position left, center, or right using HTML container wrapper tags.

To align text or assets to the left (Explicit layout style):

<div align="left">
    This text and any assets here will sit on the left side.
</div>

To center text, images, or assets:

<div align="center">
    This text and any assets here will be centered.
</div>

To align text or assets to the right:

<div align="right">
    This text and any assets here will move to the right side.
</div>

2. How to Add Links

Adding clickable text hyperlinks inside your profile README is easy. Put the text you want users to click inside square brackets, followed by the actual web URL inside parentheses.

[Click here to see my website](https://github.io)

3. How to Add Photos & Images

To display an image directly on your profile, use an exclamation mark first, then an alt-text description inside square brackets, followed by the direct image file URL inside parentheses:

![My Custom Banner Image](https://your-image-url-here.png)

Recommended Image Hosting Platforms

Since you need direct file links (ending in .png, .jpg, or .gif) to make images show up on GitHub, use these free image and asset hosting options:

  • File Garden: An excellent free platform for uploading permanent digital assets, pixel art sprites, and custom graphics templates.
  • Catbox.moe: A simple file host that provides fast, direct raw file URLs perfect for custom README badges and images.

Image Sizing

Standard Markdown tags do not allow you to resize photos. To prevent layout scaling issues, use the HTML image tag to specify the width or height explicitly.

<img src="your-image-url-here.png" width="200" />

4. How to Add Colored Text

GitHub strips away normal HTML inline styling for colors. To bypass this restriction and insert colored text on a README profile, you must use standard LaTeX math markup blocks.

To write text in a specific color, use this syntax pattern:

$\color{HexColorCode}{\text{Your text here}}$

Example for bright green text:

$\color{#00AC60}{\text{This text is custom green}}$

Use these external platforms to adjust gradients, build technical status badges, or prepare your graphic canvas elements:

  • Shields.io: Create static or dynamic color-blocked profile badges with custom icon tags.
